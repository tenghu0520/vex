Clawbot Controller Lab
VEX V5 · C++ coding lab · Clawbot

Drive a robot with code, one line at a time

This program turns the controller into a robot driver. The two sticks drive the wheels. The R1 and R2 buttons move the arm and the claw. Push a stick or press a button on the controller, then press Next step to see how each line reads it. Press Real speed to drive for real!

Rule 1: read top to bottomRule 2: do one line at a timeRule 3: a motor keeps spinning until the code changes it
Lab 1 · You are the driver and the programmer

Sticks → wheels, buttons → arm and claw

The yellow arrow ▶ shows the line the robot is reading. The code is yours: click inside it and type. With Run as I type on, the robot restarts with your new code. Click a line number to learn what that line means.
