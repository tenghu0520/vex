# vex

Interactive VEX V5 coding labs for kids. Open a file in a web browser.

- **VEX Bumper Lab.html**: step through the bumper sensor program line by line, write on the Brain screen, practice `%d`.
- **VEX Clawbot Lab.html**: drive a Clawbot with a virtual controller and step through the class driving program (sticks, wheels, arm and claw).

In both labs you can edit the code and see the robot react right away.
