Lab 2 · Writing on the screen

    
printAt(x, y, "text") tells the robot where to write

    
The V5 Brain screen is 480 dots wide and 240 dots tall. x is how far across (→). y is how far down (↓). The top-left corner is (0, 0). Move the sliders. The yellow dot is where your text will start.

  

  

    

      
(0, 0)480 wide →

      

      
↓ 240 tall(480, 240)

    

    

      

      

      

      

      

        
        
        
      

      
Secret: if new text is shorter than old text, the end of the old text stays. Write Hi at (1, 20) and you get Himp! That is why the example writes "pomp     " with spaces at the end. Spaces work like an eraser.

    

  






  

    
Lab 3 · Showing numbers with %d

    
%d is a seat saved for a number

    
Text in quotes never changes by itself. To show a number that changes, like speed, put %d in the text. Then put the number after a comma. The robot puts the number in the %d seat. (d stands for digits, a whole number.)

  

  

    

      

      

        "Speed = %d0"
        ←
        int speed0
      

      

      

    

    

      

      

        
        
        
        
      

      
      
Try this: press speed = 10;, then speed = 9;. The screen says Speed = 90! The 0 from 10 was never erased. Now tick the box and try again. The spaces erase the old digits.

      
You can use more than one seat: printAt(1, 60, "x=%d y=%d", x, y). The first number goes in the first seat, the second number in the second seat.

    

  






  

    
Lab 4 · The true/false box

    
bool: a box for true or false

  

  

    

      
bool bumper = BumperH.pressing();

      

        
false

        
      

      
A bool box is picky. It only holds two things: true (yes) or false (no). This line asks the bumper “Are you pressed?” and puts the answer in a box named bumper.

    

    

      
One equals sign or two? Big difference!

      

        =
Put it in. x = 5 means “put 5 into the box x”. Like dropping candy into a jar.

        ==
Ask: are they the same? x == 5 means “Is x equal to 5?” The answer is true or false.

      

      
Remember: one = does something. Two == asks something. Inside the ( ) of an if, you ask, so you use ==.
